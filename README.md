# AI Interview Simulator

## About the Project

I built this project to help students and job seekers practice interviews in a more interactive way. Instead of reading interview questions from a PDF or website, users can have a conversation with an AI interviewer and receive feedback on their responses.

The goal of this project is to make interview preparation more realistic, accessible, and engaging.

---

## Features

- AI-powered interview conversations
- Technical and HR interview modes
- Instant feedback after each interview
- Performance analysis and scoring
- Clean and responsive user interface
- Easy-to-use workflow

---

## Tech Stack

**Frontend**
- React
- JavaScript
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**AI**
- OpenAI API

---

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MadhavGoyal2006/ai-interview-simulator.git
```

Go to the project folder:

```bash
cd ai-interview-simulator
```

Install the required packages:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Why I Built This

Interview preparation often feels repetitive and doesn't provide personalized feedback. I wanted to build something that feels closer to a real interview experience while also helping users understand where they can improve.

This project also gave me the opportunity to strengthen my skills in full-stack development and working with AI APIs.
